# Canonical C2 exports

> **Primary hero is airborne `S2_osint_swarm`. Maritime secondary track is `S1_trojan` (tri-service + GLINT hull anchor) then `S3_sar_ais` (GLINT macro × SIA × AIS dark vessel). marun `scenario_02_conflicting` is a legacy fusion bench, not Nexus S2.**

This directory houses time-compressed, canonical multi-service exports consumed by Nexus C2.

## Pillar 2: `s1_trojan` export

Time-compressed, multi-service JSONL and companion metadata for Nexus C2
ingestion (`s1_trojan`). Generated by
[`generate_canonical_stream.py`](../generate_canonical_stream.py) from:

- [`../scenario_01_consistent/synthetic_airbase_data/`](../scenario_01_consistent/synthetic_airbase_data/)
- [`../scenario_01_consistent/synthetic_armybase_data/`](../scenario_01_consistent/synthetic_armybase_data/)
- [`../synthetic_maritime_data/`](../synthetic_maritime_data/)

Land/air JSON keep their existing Changi-east geometry. The story
contradiction (AIS ~6.1 kt vs coastal radar ~120 kt) comes from the maritime
overlay. Story EW bearings toward the mothership are appended as overlay rows.

### Demo time compression

Wall clock `14:30:00`–`15:00:00` (1800 s) maps onto a ~184 s pitch window via
`time_s` on each JSONL row.

### Files in this directory

```text
exports/
  s2_osint_swarm_scenario.jsonl   # Pillar 1 (Primary Hero)
  s1_trojan_scenario.jsonl        # Pillar 2: Trojan mothership
  site_origins.json
  pois.json
```

- `s2_osint_swarm_scenario.jsonl` — 6 Nexus-shape events for Pillar 1.
- `s1_trojan_scenario.jsonl` — 228 newline-delimited events with `service`,
  `source`, and sensor fields.
- `site_origins.json` — `AIRBASE_01` / `ARMY_BASE_01` / mothership origins for
  polar reverse-geocode.
- `pois.json` — copy of maritime POIs (Jurong CNI + military stubs) for ETA /
  debris gates.

### JSONL row shape (typical, Pillar 2)

Polar air/army rows include `site_lat`, `site_lon`, and either `azimuth_deg` +
`range_km` or `bearing_deg`. Maritime geodetic rows include `lat` / `lon`
(and speed fields such as `sog_knots` or `velocity_knots`). Every row has:

```text
time_s, service, source, sensor_id, timestamp
```

`service` values include `AIR_FORCE`, `ARMY`, and `NAVY`.

## Regenerate

```text
# Pillar 1 (S2)
python generate_s2_osint_swarm_export.py

# Pillar 2 (Trojan) — prerequisite: airbase, armybase, and maritime generators
python generate_maritime_overlay.py
python generate_canonical_stream.py
```

Nexus loads exports via `MARUN_EXPORT_DIR` or the sibling path
`marun-sensor-simulation/exports/` (CI uses vendored copies under
`sdth-nexus-c2/tests/fixtures/`).
